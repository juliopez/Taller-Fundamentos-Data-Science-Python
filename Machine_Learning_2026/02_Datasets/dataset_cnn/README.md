# Dataset CNN — Piedra, papel o tijera

Directorio destinado al archivo `dataset_cnn.zip` para el notebook introductorio de redes neuronales convolucionales (CNN).

## Contenido previsto

El archivo ZIP contendrá 600 imágenes PNG distribuidas en tres categorías (`rock`, `paper`, `scissors`): 450 imágenes de entrenamiento (150 por clase) y 150 de prueba (50 por clase).

Estructura interna del ZIP:

```text
dataset_cnn/
├── train/
│   ├── rock/
│   ├── paper/
│   └── scissors/
└── test/
    ├── rock/
    ├── paper/
    └── scissors/
```

La validación se separará del conjunto de entrenamiento en el notebook. Los estudiantes descargarán el ZIP desde este directorio y lo cargarán a Google Colab.
