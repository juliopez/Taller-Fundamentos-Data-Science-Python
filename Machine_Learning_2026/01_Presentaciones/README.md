# Presentaciones — Machine Learning 2026

Esta carpeta contiene las **presentaciones utilizadas durante las 18 semanas de la asignatura Machine Learning 2026**.

Las presentaciones acompañan la progresión de contenidos del curso y el desarrollo del **Proyecto Integrador de clasificación de imágenes mediante Redes Neuronales Convolucionales (CNN)**.

## Organización

| Semana | Contenido principal |
|---|---|
| **Semana 01** | Introducción al Machine Learning |
| **Semana 02** | Aprendizaje supervisado y no supervisado |
| **Semana 03** | Redes neuronales: fundamentos |
| **Semana 04** | Entrenamiento de redes neuronales |
| **Semana 05** | Datos para clasificación de imágenes |
| **Semana 06** | Preparación y transformación de datos |
| **Semana 07** | Validación y generalización |
| **Semana 08** | Data Augmentation |
| **Semana 09** | Introducción a Deep Learning y CNN |
| **Semana 10** | Arquitecturas CNN |
| **Semana 11** | LSTM, Autoencoders y GAN |
| **Semana 12** | Transfer Learning y Fine-Tuning |
| **Semana 13** | Evaluación y mejora de modelos |
| **Semana 14** | Optimización de modelos |
| **Semana 15** | Interoperabilidad y ONNX |
| **Semana 16** | Implementación de modelos |
| **Semana 17** | Despliegue y operación |
| **Semana 18** | Producto final y cierre del proyecto |

## Relación con el proyecto integrador

Los contenidos avanzan progresivamente desde los fundamentos de Machine Learning hasta la implementación y despliegue de una solución completa de clasificación de imágenes:

**Fundamentos → Redes neuronales → Datos → CNN → Transfer Learning → Optimización → ONNX → Streamlit → GitHub → Streamlit Community Cloud**

Las presentaciones deben utilizarse en conjunto con los **notebooks prácticos**, actividades y evaluaciones disponibles en las demás secciones del curso.
