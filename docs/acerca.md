# Acerca del proyecto

<p class="portal-lead">Un espacio de recursos educativos abiertos para aprender ciencia de datos, Machine Learning y Deep Learning mediante materiales reutilizables y actividades prácticas.</p>

## Propósito

Facilitar el aprendizaje autónomo de Python, análisis de datos, modelado predictivo y redes neuronales, tanto para quienes comienzan como para quienes desean profundizar en aplicaciones de inteligencia artificial.

## Cómo está organizado

El portal presenta **rutas de aprendizaje**, una **biblioteca de recursos** y un **laboratorio interactivo**. El repositorio de GitHub almacena los archivos originales, notebooks, datasets y documentación técnica.

Los recursos proceden de materiales educativos desarrollados en distintos contextos. Algunos archivos mantienen referencias históricas a sesiones, semanas o actividades evaluadas. Estas referencias no implican matrícula, calendario ni evaluación obligatoria para utilizar el portal.
