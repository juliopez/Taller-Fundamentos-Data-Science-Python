7. Código del slide
modelo = Sequential([
    Dense(128, activation='relu', input_shape=(784,)),
    Dense(4, activation='softmax')
])

modelo.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
Arquitectura: 784 entradas → 128 unidades con ReLU → 4 salidas con Softmax.
Entrenamiento: loss mide el error; Adam guía la actualización de parámetros; accuracy permite observar el porcentaje de aciertos.
