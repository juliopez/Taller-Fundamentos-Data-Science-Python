# Notebooks prácticos — Machine Learning 2026

Esta carpeta contiene los **notebooks de Google Colab** utilizados para desarrollar las actividades prácticas de la asignatura y apoyar progresivamente la construcción del **Proyecto Integrador de clasificación de imágenes mediante Redes Neuronales Convolucionales (CNN)**.

Los notebooks están organizados siguiendo la progresión de contenidos del curso.

| Notebook | Semanas | Contenido |
|---|---:|---|
| **NB01 — Introducción a redes neuronales** | 3–4 | Construcción, entrenamiento, validación y predicción mediante una red neuronal básica. |
| **NB02 — Preparación y gestión del dataset de imágenes** | 5–8 | Exploración, limpieza, transformación, normalización, división del dataset y Data Augmentation. |
| **NB03 — Construcción y entrenamiento de una CNN** | 9–10 | Construcción de una CNN, entrenamiento, curvas de aprendizaje, evaluación y comparación de arquitecturas. |
| **NB04 — Transfer Learning, Fine-Tuning y evaluación de CNN** | 12–13 | Transfer Learning, Fine-Tuning, evaluación mediante test, matriz de confusión y selección del modelo definitivo. |
| **NB05 — Optimización, interoperabilidad y ONNX** | 14–15 | Optimización, cuantificación, poda, medición de inferencia, exportación a ONNX y ONNX Runtime. |
| **NB06 — Aplicación y despliegue del modelo** | 16–17 | Integración del modelo con Streamlit, GitHub y despliegue mediante Streamlit Community Cloud. |

## Secuencia de trabajo

NB01 → NB02 → NB03 → NB04 → NB05 → NB06

Los notebooks se encuentran relacionados entre sí y acompañan las diferentes etapas del Proyecto Integrador:

**Fundamentos → Dataset → CNN → Modelo definitivo → Optimización → Implementación y despliegue**

## Uso en Google Colab

Los archivos `.ipynb` pueden abrirse y ejecutarse directamente mediante **Google Colab**, sin necesidad de instalar Python ni las bibliotecas utilizadas en el curso en el computador local.

Se recomienda trabajar sobre una **copia personal del notebook en Google Drive**, manteniendo sin modificaciones la versión original disponible en este repositorio.
