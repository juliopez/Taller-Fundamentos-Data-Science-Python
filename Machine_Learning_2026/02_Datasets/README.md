# Datasets

Este directorio contiene los conjuntos de datos utilizados en las actividades prácticas, notebooks y ejercicios del curso de Machine Learning.

## Organización

Cada dataset incorporado al directorio debe estar acompañado por su correspondiente **diccionario de datos**, en un archivo independiente.

La estructura recomendada es:

```text
dataset/
├── README.md
├── nombre_dataset.csv
├── nombre_dataset_diccionario.md
└── ...
```

## Uso de los datasets

Los conjuntos de datos disponibles en este directorio pueden utilizarse para actividades de:

- exploración y análisis de datos;
- limpieza y preparación;
- transformación de variables;
- visualización;
- entrenamiento y evaluación de modelos de Machine Learning;
- otras actividades prácticas definidas durante el curso.

Antes de utilizar un dataset, revise su respectivo diccionario de datos para conocer el significado, tipo y características de sus variables.

## Consideraciones

Los datasets pueden tener distintos orígenes y propósitos. Algunos pueden contener deliberadamente problemas de calidad de datos como parte de una actividad académica.

Cuando corresponda, el archivo de diccionario o la documentación asociada indicará:

- descripción del conjunto de datos;
- significado de las variables;
- tipos de datos;
- unidades o categorías;
- observaciones relevantes para su utilización.

> Los datasets destinados exclusivamente a actividades pedagógicas pueden contener datos ficticios o modificados. Revise siempre la documentación específica antes de utilizarlos.
