# Machine Learning y Deep Learning

[← Inicio](index.html) · [Catálogo completo](catalogo.html)

Materiales para avanzar desde los fundamentos de clasificación y redes neuronales hasta el desarrollo de una **aplicación de clasificación de imágenes**. Cada recurso se puede consultar de forma independiente.

## Ruta sugerida de aprendizaje

**Fundamentos → Redes densas → Preparación de imágenes → CNN → Entrenamiento con dataset propio → Transfer Learning → Optimización → Despliegue**

## Simuladores interactivos

1. [**Simulador de redes neuronales**](Simulador_Redes_Neuronales.html): capas densas, funciones de activación e hiperparámetros.
2. [**Simulador introductorio de CNN**](Simulador_CNN.html): convoluciones, filtros, pooling y arquitectura.
3. [**Laboratorio de optimización CNN**](Simulador_Laboratorio_Optimizacion_CNN.html): hipótesis, configuraciones y comparación de métricas.

Los simuladores son recursos de apoyo; el entrenamiento y la evaluación se realizan en los notebooks.
