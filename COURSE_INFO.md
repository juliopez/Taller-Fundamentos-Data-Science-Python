# Información del curso

## Taller
Fundamentos de Data Science con Python

## Autor
Julio López-Núñez

## Descripción

Este taller introduce conceptos fundamentales de ciencia de datos utilizando Python.

Los participantes aprenderán a:

- manipular datos
- visualizar información
- entrenar modelos básicos de machine learning

## Público objetivo

- docentes
- académicos
- profesionales interesados en análisis de datos
