## Proyecto Integrador

El proyecto se desarrolla progresivamente durante el semestre:

**Problema → Dataset → CNN → Modelo definitivo → Optimización →
Aplicación → Despliegue**

## Flujo tecnológico

**Google Colab → Modelo CNN → ONNX (cuando corresponda) → Streamlit →
GitHub → Streamlit Community Cloud**

El producto final corresponde a una aplicación funcional de
clasificación de imágenes, desplegada y accesible mediante una URL.
